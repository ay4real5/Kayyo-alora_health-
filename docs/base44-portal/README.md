# Base44 patient portal

The patient portal is built in Base44 by the owner (ROADMAP P3-16), not in this repo. This folder holds
what the owner needs to build it:

- `openapi-portal-spec.json` — generated from the API (task P1-10 adds the export script).
- `portal-screens.md` — prompts/specs for each of the 7 screens (task P3-15).
- `integration-notes.md` — auth flow, custom domain, idle timeout (task P3-15).

⚠ Read OPEN_QUESTIONS Q-002 first: the auth approach in the original design must change before building.
